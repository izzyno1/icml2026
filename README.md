按旧十篇批次和三篇 Pro 实测作保守分组并发预算：

| 容量方案 | 处理时间情景 | 每天八小时折算 |

| 6000 摘要＋700 Pro，四并发 | 69.02–72.26 小时 | 8.63–9.03 天 |
| 6000 摘要＋700 Pro，五并发 | 64.35–66.94 小时 | 8.04–8.37 天 |

这是预算模型，不是并发实测或置信区间。保留逐篇整理、传递、回收和解析成本，仅将等待分组，不能把总墙钟除以五。滚动补位、摘要与 Pro 重叠的节省须实际测量。

三天指 **72 小时持续可操作窗口**，不等于三天每天八小时。五并发只有约 5–8 小时余量；目录、未缓存正文取得、限流、图像补读和新增报告汇总等未测成本须占用余量。两天不是承诺，三天也有条件。遇到真实边界保存实际完成数，不模拟补齐，不承诺关闭会话后的后台运行。
